# Chaos-Control — Company and Team Fit

Matches are plausible skills/employer fit, not claims of company use or endorsement.

## Project thesis

A Python tool that reads records from several sources, converts them into one common format and lets multiple sources be read concurrently.

## Databricks

**Relevant public technical areas:** Data ingestion, streaming and lakehouse pipelines.

**Potential roles:** Data Engineer, Backend Engineer, Platform Engineer, Distributed Systems Engineer or Python Engineer.

**Evidence to build:** Single-file asynchronous Python collector that reads JSONL/NDJSON, CSV and plain text, recursively walks directories, and optionally streams line-oriented HTTP(S) responses using httpx. A bounded queue/semaphore provides concurrency and source errors can be isolated. It is a collector library/prototype, not a complete production data platform.
